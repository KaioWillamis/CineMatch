# 🎬 CineMatch

**Encontre filmes que combinam com você!**

O CineMatch é um projeto acadêmico de desenvolvimento web que tem como objetivo facilitar a descoberta de filmes de acordo com os gostos e as preferências dos usuários.

Diante da grande quantidade de filmes disponíveis, a plataforma busca tornar a escolha mais simples e intuitiva, oferecendo a possibilidade de explorar títulos e encontrar opções de acordo com os interesses de cada pessoa.

## 🎯 Objetivo do projeto

Desenvolver uma plataforma web que ajude os usuários a encontrar filmes de seu interesse, reduzindo a dificuldade de escolha causada pela grande variedade de opções disponíveis.

## ✨ Funcionalidades planejadas

- 🔎 Busca de filmes por título.
- 🎭 Filtros por gênero cinematográfico.
- 📅 Pesquisa por ano de lançamento.
- ⭐ Consulta às avaliações dos filmes.
- 🎞️ Exibição de informações e pôsteres.
- 💜 Recomendações de filmes de acordo com as preferências dos usuários.
- 📱 Interface responsiva para computadores e dispositivos móveis.

*As funcionalidades serão implementadas gradualmente durante o desenvolvimento do projeto.*

## 🛠️ Tecnologias

- HTML5 — estrutura das páginas.
- CSS3 — estilização e responsividade.
- JavaScript — interatividade e lógica da aplicação.
- TMDB API — fonte planejada para obtenção de informações sobre filmes.

## 🚀 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone URL_DO_SEU_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd CineMatch
   ```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

## 🎓 Contexto acadêmico

O CineMatch foi idealizado a partir do seguinte problema:

**Dificuldade dos usuários em encontrar filmes de acordo com seus gostos e preferências, devido à grande quantidade de opções disponíveis.**

O projeto busca aplicar conhecimentos de desenvolvimento web na criação de uma solução prática para esse problema.

## 👨‍💻 Autoria

Desenvolvido como projeto acadêmico em equipe.

## 📄 Créditos

A integração com a API do TMDB está planejada para fornecer informações sobre filmes. Caso seja utilizada, a aplicação deverá seguir as condições de uso e os requisitos de atribuição do TMDB.

Este projeto não é endossado nem certificado pelo TMDB.
